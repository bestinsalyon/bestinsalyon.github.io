# BEST Lyon — Spring 2026 Course (Demo)

This is a scaffolded React + TypeScript site for BEST Lyon's Spring 2026 course. It contains pages for course description, schedule, and a survival guide. Replace dummy content with real information.

## Requirements
- Node.js (16+ recommended)
- npm

## Setup (Windows PowerShell)

```powershell
Set-Location -Path 'C:\Users\crist\Desktop\BEST'
npm install
npm run dev
```

Open the URL printed by Vite, e.g., http://localhost:5173

## Project structure
- `index.html` — App entry
- `src/main.tsx` — React entry
- `src/App.tsx` — Routes
- `src/pages/*` — Pages (Home, Course, Schedule, SurvivalGuide)
- `src/components/*` — Header, Footer, Layout
- `src/styles/main.css` — Tailwind CSS entry
